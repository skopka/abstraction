# Skopka.Abstraction

Meta-package that references all Skopka.Abstraction packages.

## Install

```bash
dotnet add package Skopka.Abstraction
```

## Included packages

- Skopka.Abstraction.OperationResult
- Skopka.Abstraction.Serialization
